# Scout Muster UX Exploration

These raster mockups explore a task-focused workflow for grouping Scouts with
similar training deficiencies while keeping the interface characterful and
non-tabular.

## Mockups

- `scout_muster_board.png` — choose a training need, select candidates, pin a
  destination cohort, and review a provisional muster.
- `scout_muster_assignment.png` — inspect one Scout's training-relevant honors
  and repeatedly queue transfers into a pinned destination squad.
- `scout_muster_berthing_conflict.png` — resolve full-ship capacity through a
  reciprocal swap, squad reberthing, or a focused Classis handoff without
  losing the muster plan.

## Prompt set

The images were generated as high-fidelity 16:9 desktop game UI mockups using
the Apothecarium unit-rollup baseline as a style-only reference.

Shared direction:

- Matte-black panels with thin antique-brass borders.
- Warm ivory geometric typography and restrained status colors.
- Practical Godot UI hierarchy, not concept art or a modern SaaS dashboard.
- Card-based dossiers, training seals, and portrait medallions instead of
  spreadsheet rows and dense columns.
- Original heraldic motifs and ship icons.

Screen-specific prompts:

1. **Muster board:** Four training-need seals, a filtered candidate-card list,
   pinned squad cohorts, and a provisional command ledger.
2. **Assignment review:** One selected Scout dossier with four training-status
   seals beside a pinned destination squad and persistent queue controls.
3. **Berthing conflict:** A modal offering reciprocal swap, reberthing, or a
   focused Classis handoff while preserving all provisional orders.
