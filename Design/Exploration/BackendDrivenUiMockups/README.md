# Backend-driven UI mockups

These mockups were designed from the project's backend models and services. Existing front-end scenes, UI scripts, themes, and presentation helpers were intentionally excluded from the review.

## Visual direction

The shared interface language combines blackened steel, worn bronze, parchment ivory, cyan instrumentation, amber uncertainty, and restrained crimson threats. Decoration is kept on panel edges so that maps, rosters, inventories, and forecasts remain readable.

The supplied images were treated only as broad visual references:

- star-map topology and strategic scale;
- modular character inventory layout;
- progressive bronze rank framing;
- compact cyan progression columns.

No reference interface or insignia was intended to be reproduced directly.

## Screen concepts and backend anchors

### 01 — Sector Command

Anchored in `Sector`, `Subsector`, `Planet`, `WarpLane`, `TaskForce`, `FleetRoute`, governance tiers, faction relationships, and governor requests. The screen makes route time, capacity, subsector control, petitions, and uncertain contacts visible without leaving the sector map.

### 02 — Planetary Operations

Anchored in the planet's fixed sixteen-region diamond, `RegionFaction`, intelligence, population and carrying capacity, regional defenses, `MissionType`, `Order`, and `Aggression`. The order drawer exposes the backend's quiet/active-engagement choices as clear operational language.

### 03 — Chapter Armoury

Anchored in squads, boarded ships, training focus, equipment loadouts, armor and weapon profiles, carrying capacity, equipment requirements, ammunition, and initial ready order. It separates doctrine-level actions from equipping the selected brother.

### 04 — Apothecarium

Anchored in combat effectiveness, wound locations, recovery weeks, progenoid status, cybernetics, replacement procedures, requisition costs, and procedure prerequisites. The layout links a selected wound directly to the proposed treatment.

### 05 — Recruitment Program

Anchored in recruitment policy and world type, staff roles, screening filters, cohorts, candidates, aspirants, thirteen implantation phases, Black Carapace, waitlists, survival forecasts, training capacity, and weekly requisition cost.

## Final prompt set

All five images used the built-in image-generation mode and the `ui-mockup` use case at high-fidelity 16:9 desktop-game scale.

1. **Sector Command:** An original shippable sector command interface with subsectors, connected planets and warp lanes, selected-world governance and intelligence, petitions, task-force travel, objective/subjective warp time, ship capacity, and soldier capacity. Map-dominant composition; charcoal, bronze, ivory, cyan, amber, and restrained crimson.
2. **Planetary Operations:** An original planetary command interface centered on exactly sixteen diamond-arranged regions in rows of 1-2-3-4-3-2-1, with faction control, intelligence, population, carrying capacity, garrison strength, four defense meters, and a Recon order drawer exposing quiet, observe, and cautious behavior.
3. **Chapter Armoury:** An original squad armoury with a full-body equipment layout, one 7x5 inventory grid, weapon comparison, load capacity, ready order, squad location and training focus, plus separate save-doctrine and equip-squad actions.
4. **Apothecarium:** An original medical dossier with roster hierarchy, compact rank medallion, body-location diagnostic, combat status, recovery, gene-seed risk, wound rows, a bionic replacement procedure, requisition cost, duration, and prerequisite checklist.
5. **Recruitment Program:** An original recruitment pipeline with home-world policy, three staff roles, screening filters, cohort funnel, thirteen ordered implantation phases culminating in Black Carapace, selected-aspirant details, coverage, waitlist, expected annual battle-brothers, and weekly cost.

Shared constraints across all prompts: polished practical product UI rather than concept art; original composition; no logo, watermark, copied insignia, excessive skull ornament, neon-green wash, mobile layout, or illegible paragraph text.
